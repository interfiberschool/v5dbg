# v5dbg
v5dbg is an experimental real-time debugger for V5 C++ programs

<img width="3789" height="1894" alt="image" src="https://github.com/user-attachments/assets/ce460835-18f0-47c0-9e6e-89d98043fe6c" />

## Features
v5dbg implements many common debugger features you may be used to in debuggers such as `gdb`, `lldb`, or the builtin `Visual Studio debugger`

- [x] View variable memory
- [x] Set the value of variables during debugging
- [x] View stacktraces for each active thread
- [x] Set breakpoints
- [x] Set conditional breakpoints
